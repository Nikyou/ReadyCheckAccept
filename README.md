## Introduction

**Ready Check Accept** is a simple addon to automatically accept ready checks with delays and on conditions.

## Usage

* `/rca` - opens addon settings out of combat
* `/rca on` - enables automatic accept of readycheck
* `/rca off` - disables automatic accept of readycheck

## Key Features

* Customisable delay before ready check accept
* An option to not accept ready check when you are /afk
* Options for conditions in party and raid groups when to accept ready check:
    * When in instance
    * When out of instance
    * When dead / ghost
